# Добавление нового типа дома (краткий план)

Файлы: вся геометрия дома — `crates/kolomna-render/src/piter.rs` (`generate_manor`),
выбор типа и расстановка по кварталу — `crates/kolomna-app/src/win.rs`
(`place(...)` в `load_scene`).

## Шаги

1. **Флаг типа** — добавь параметр в `generate_manor(...)` (сейчас:
   `seed, arch, size, corner, roman, bays`) и поле в `struct Manor`.
   Флаг копируется в `Manor` при сборке.
2. **Геометрия** — новая функция `impl Manor` (образец: `erkers()` или
   `roman_portico()`); вызывай её из `build()` (для фильтров пересечений — ДО
   зависимых циклов: `erkers()` зовётся до стен/балконов и кладёт свои x-спаны
   в `self.bay_x`). Готовые хелперы: `face(mat, quad)` — квад с дефолтным uv;
   `wall_quad(mat, side, t0, t1, y0, y1, plane)` — «стенный» квад с
   тайловым uv (side 0=юг(+z), 1=север, 2=запад, 3=восток); `self.b.quad`
   для полного контроля uv.
3. **Материалы** — используй существующие слоты (`M_BASE, M_BASE_WIN, M_RUST,
   M_WALL, M_WIN, M_WIN_SANDRIK, M_WIN_ARCH, M_BAND, M_DOOR, M_BLACK_DOOR,
   M_STABLE, M_WIN_PLAIN, M_STONE`). Новый слот материи = новому слоту ОБЯЗАТЕЛЬНО
   текстуру в `textures()` (иначе чёрно-фиолетовые квадраты) + обнови
   `N_MATS`. Текстуры хранятся снизу вверх: `flip_rows` в конце `textures()`
   делает это сам, рисуй как видишь.
4. **Пересечения с существующим** — все зоны вырезки перечисляй явно:
   `door_tile ±1` (вход/козырёк/фонари), `arch`-тайлы (проезд), эркеры
   (`bay_x`, ±0.6), портик у roman (|x−xc| < 4.6), трубы (`chim_x`, слуховые
   ≥1.6 м). Если элемент занимает спаны — сохрани их в поля Manor и добавь
   `continue` в чужие циклы (пример: балконы скипают `bay_x`).
5. **Габариты** — стены кратны 2 м (тайлы 2×3 м): нечётная ширина даёт щель.
   Элемент не ставится на самый крайний тайл (наличник у угла — ошибка);
   верх/низ в метрах от пола (пол = y0 меша).
6. **Выбор типа в win.rs** — как `roman`/`bays`: улично-рядный кусок улицы
   (`i == 0`, самый широкий ≥12–14 м) под rng-долей; флаг пробрасывается
   через `place(..., bay, seed)`. Квартал — 10 дворов, у каждого k=1 в улице,
   поэтому типы конкурируют за один кусок: roman (0.6) → bays (0.8) → plain.
7. **Проверка** — `export PATH="/e/tools/mingw-tools-only:$PATH"; cargo build`;
   `./target/debug/kolomna-app.exe --shot out/x.png --zoom 30`;
   пиксель-чек: 0 magenta; лог печатает `block N street row: arches/roman/bays`.
   Release: `cargo build --release` → `cp -f target/release/kolomna-app.exe Kolomna.exe`.
   Смоук окна: запустить exe, 10–15 с, лог без panic (UI-кнопка живёт только в оконном режиме).

## Существующие типы
- **обычный доходный** — руст, наличники, балконы, парадная дверь с козырьком;
- **арка** — гарантированный проезд 4×4.6 м сквозь улично-рядный дом;
- **римский** (`roman`) — 4 колонны, фронтон, перрон, двухэтажный портал;
- **угловой** (`corner`) — второй парадный фасад на востоке;
- **с эркерами** (`bays`) — выступы 4×0.85 м со 2-го этажа, щёки+консоли+карнизик.

## Очередь идей (старый Питер)
ротонда-угол (скруглённый угол), кариатиды/атланты, особняк с курдонёром,
«кирпичный стиль» (неоштукатуренный), дом-комод (барочный), модерн (майолика,
криволинейные щипцы).
