# Шрифты

Ресурсы интерфейса приложения (`crates/kolomna-app`). Все шрифты распространяются
под свободными лицензиями (OFL — в редакции Google Fonts):

- Golos Text — Paratype, OFL
- Montserrat — Julieta Ulanovsky и др., OFL
- Onest — Dmitri Voloshin, OFL
- PT Sans (Bold) — ParaType, OFL
- Rubik — Hubert & Fischer, Meir Sadan, OFL

Полные тексты лицензий — на страницах соответствующих шрифтов в Google Fonts.
